Four temperaments for one dossier

Each mock is a complete, self-contained treatment of the same artifact — the Consumer Price Index dossier — with the same data, the same sections, and a different idea of what the page should feel like. Open them full-width; the charts are the protagonists.

  1. MOCK 01The Monograph A printed volume: Caslon and Newsreader, hairline rules, numbered plates, drop caps. Scholarly, quiet, permanent.
  2. MOCK 02The Gazette A broadsheet front page: masthead, lead story for the latest print, column rules, vermilion accent. Topical, urgent, readable.
  3. MOCK 03The Abstract A statistical register: document control, framed figures with reference codes, ledger as hero. Precise, austere, verifiable.
  4. MOCK 04The Atlas Plate A survey map: one great annotated chart with numbered marginalia, sparklines in the gazetteer. Exploratory, narrative, spatial.
